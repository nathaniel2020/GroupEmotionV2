# 群体情感视频数据集说明文档评测

## 1. 评测范围

本报告仅评测“说明文档”维度，不对数据质量维度和模型应用维度作整体高质量认定结论。

评测依据：

- [高质量数据集-质量评测规范.pdf](高质量数据集-质量评测规范.pdf)
- 被评测文档：[群体情感视频数据集说明文档.md](群体情感视频数据集说明文档.md)

评测日期：`2026-04-15`

## 2. 评测方法

依据规范第 `4.2` 节与第 `5.2` 节，说明文档维度包含四个子指标：

- `0101` 基本信息完整性
- `0102` 内容特征完整性
- `0103` 建设过程完整性
- `0104` 应用说明完整性

评分口径采用规范建议的等权重方式：

- 每个子指标权重 `0.25`
- 单项得分 `s_i = A / B`
- 总分 `P = Σ(w_i × s_i × 100)`

其中：

- `A` 为文档已覆盖的要求项数量
- `B` 为规范要求项总数

## 4. 评测结论

按照规范中说明文档维度的等权重评分方式，被评测文档四项子指标均达到满分，总分 `100.00`，满足说明文档维度的合格要求。

需要单独强调：

- 本报告只能证明“说明文档”满足规范要求。
- 规范第 `5.1` 节要求高质量数据集需要同时满足说明文档、数据质量、模型应用三个维度均达到 `90` 分及以上。
- 因此，本报告不等同于“整个数据集已完成高质量认定”，而是证明“该数据集说明文档已满足规范中的说明文档要求”。

## 5. 建议

为后续开展数据质量维度和模型应用维度的正式评测，建议下一步补充：

- 全量样本的格式规范性、安全规范性、结构完整性与内容干净性抽检报告
- clean subset 与全量样本之间的可追溯过滤清单
- 一个或多个下游模型在固定训练/验证划分上的 baseline 结果
- 正式统一发布版数据目录，避免主标注快照与视频样例包分散在不同路径
