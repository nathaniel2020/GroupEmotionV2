本说明文档依据《高质量数据集 质量评测规范》编制，用于配套说明群体情感视频数据集的基本信息、内容特征、建设过程和应用方式。

本版文档按 `20 万条 clip 级样本` 的交付目标口径编写。

## 4. 数据建设过程

### 4.1 数据来源

本数据集主要来源于公开可获取的视频内容及项目内部整理的数据资产，重点围绕“群体互动场景”和“群体情绪触发事件”进行筛选与组织。

### 4.2 采集原则

数据采集遵循以下原则：

- 场景相关性：优先保留能够体现群体互动与群体情绪变化的视频内容。
- 事件相关性：优先覆盖具有明确触发机制的群体情绪场景。
- 样本可用性：优先保留适于切分、标注和模型消费的视频内容。
- 溯源可追踪：保留必要的视频元信息和样本映射信息。

### 4.3 加工处理流程

数据处理一般包括以下阶段：

1. 数据源检索与候选视频收集
2. 视频有效性筛选
3. 视频切分与 clip 生成
4. 文本/字幕/元信息整理
5. 结构化标注生成
6. 标注结果校验
7. 交付版样本导出

其中，交付版数据仅保留面向消费方所需的最终样本文件和标注文件，不包含内部处理缓存和临时中间结果。

### 4.4 标注规范

本数据集采用结构化标注规范，要求：

- 字段名称固定
- 必填字段完整
- 枚举字段取值受控
- 数值字段范围受控
- 说明性文本字段语义明确
- 标注结果可被统一解析和批处理

质量控制方式包括但不限于：

- 枚举值合法性校验
- 数值范围校验
- 条件必填项校验
- 样本级人工抽检 `【待补充：抽检比例】`
- 失败样本回退与重标机制 `【待补充】`

- 每次交付应具备唯一版本号
